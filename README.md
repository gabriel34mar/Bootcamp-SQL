## About the Course

This course focuses on learning SQL and MySQL from the fundamentals through more advanced database concepts and practical data analysis.

The course covers topics including:

- SQL fundamentals
- MySQL 8.x
- Databases and tables
- Data types
- INSERT, SELECT, UPDATE and DELETE
- CRUD operations
- Primary keys and constraints
- String functions
- Filtering and refining queries
- Aggregate functions
- GROUP BY
- Subqueries
- Date and time functions
- JOINs
- Database relationships
- Views
- Window functions
- Working with real-world datasets
- SQL-based data analysis and reporting
